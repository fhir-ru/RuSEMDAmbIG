Замечания относятся к единственному комплектному XML СЭМД 290 редакции 7, идентифицированному на странице [источников](scope.html). Они отделяют неполноту для обмена и неоднозначность семантики от нарушения схем. Исходный пример проходит проверенные XSD и схематрон; приведённые ниже замечания не объявляются нарушениями этих правил. Исходник не исправляется.

### SRC7-01 — пространство нумерации медицинской карты

В componentOf/encompassingEncounter указаны code типа карты и medService:DocNumber `5499-16`. Тип: «Амбулаторная медицинская карта», НСИ `.723`, code `1`, version `1.1`. Полного II карты с root и extension нет. Имеющийся идентификатор с окончанием `.15` относится к случаю/посещению.

Тип и номер позволяют прочитать реквизит, но не задают границы уникальности. Пространство `.17` нельзя выводить из идентификатора посещения без дополнительного соглашения. В IG используется логическая ссылка Encounter.partOf с номером и типом без identifier.system.

Предложение к сопровождению исходного пакета: явно указать пространство нумерации карты либо правило его определения и границы уникальности номера. Замечание к источнику сохраняется после закрытия R7-01 маппинга.

### SRC7-02 — Диаскинтест в секции «Иммунизация»

В IMM/entry/observation указан Диаскинтест: НСИ `.1078`, code `1`, version `6.5`, дата `2025-05-01`. Содержательный комментарий говорит о применении иммунобиологического лекарственного препарата. Эта запись не устанавливает факт вакцинации и не сообщает результат диагностической пробы.

Название секции неоднозначно относительно понятия вакцинации FHIR и может приводить к неверному выбору Immunization. В IG применяется MedicationAdministration с исходным препаратом, пациентом и датой, без encounter консультации. Отсутствующие дозу, путь, исполнителя и результат не добавляют.

Предложение к сопровождению исходного пакета: уточнить назначение секции, различить вакцинацию и применение иных иммунобиологических препаратов, отдельно описать результаты диагностических проб. Замечание сохраняется после закрытия R7-02 маппинга.

### Доза без unit

Отсутствие unit у числовой дозы для узла СМНН предусмотрено руководством редакции 7 и не регистрируется как недочёт. Смысл количества потребительских единиц раскрывается [соглашением IG](conventions.html) и Dosage.text; R7-03 закрыт.

Замечания зарегистрированы в проекте IG. Направление обращения сопровождающим исходного пакета не заявляется.
