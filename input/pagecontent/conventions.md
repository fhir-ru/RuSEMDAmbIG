Эти правила принадлежат прикладному руководству амбулаторной консультации. Их следует применять только при выполнении указанных условий. Неизвестный вариант требует проверки смысла, а не молчаливого выбора ближайшего ресурса.

### Медицинская карта без пространства нумерации

Если encompassingEncounter содержит medService:DocNumber и код типа карты, но не содержит полного идентификатора карты II, её номер и тип передаются в логической ссылке Encounter.partOf:

- Reference.type — Encounter.
- identifier.value — исходный номер карты.
- identifier.type — исходное кодирование типа карты с системой, кодом, названием и версией.
- display — понятное обозначение типа и номера.
- identifier.system отсутствует: пространство нумерации источник не сообщает.

Для комплектного примера передаётся номер `5499-16`, тип «Амбулаторная медицинская карта»: system `urn:oid:1.2.643.5.1.13.13.99.2.723`, code `1`, version `1.1`. Display: «Амбулаторная медицинская карта № 5499-16».

Идентификатор посещения с окончанием `.15` остаётся идентификатором посещения. Пространство `.17`, assigner, отдельный Encounter карты и literal reference не выводятся из него. Такой номер не обеспечивает автоматического отождествления карт между организациями или МИС. При наличии достоверного пространства номеров источник может передать его отдельно.

При отсутствии номера ссылка не формируется. Одновременное наличие полного II карты и DocNumber требует отдельного согласования: выбирать один реквизит или объединять их молча нельзя. [Замечание SRC7-01](source-issues.html).

Основания: [Encounter.partOf](https://hl7.org/fhir/R5/encounter-definitions.html#Encounter.partOf), [Reference.identifier](https://hl7.org/fhir/R5/references-definitions.html#Reference.identifier).

### Применение иммунобиологического препарата

Название секции IMM «Иммунизация» не определяет ресурс FHIR. Факт вакцинации представляется Immunization; состоявшееся применение невакцинного препарата — MedicationAdministration. Выбор опирается на подтверждённый вид препарата. Запись с неустановленным видом нельзя автоматически считать вакцинацией или назначением. Результат диагностической пробы при его наличии передаётся отдельным Observation.

В комплектном примере указан «Аллерген туберкулезный рекомбинантный в стандартном разведении|Диаскинтест|Генериум АО»: НСИ `1.2.643.5.1.13.13.11.1078`, code `1`, version `6.5`. Представление:

- MedicationAdministration.medication.concept сохраняет исходное кодирование.
- subject указывает пациента; occurenceDateTime — `2025-05-01` (имя поля FHIR R5 содержит одну r).
- status=completed выражает сообщённый факт применения, а не результат пробы или завершение курса.
- encounter не заполняется: консультация датирована `2025-05-02`, связь с посещением введения не сообщена.
- Composition.section.entry включает запись в раздел документа.

Отсутствующие дозу, путь, исполнителя, результат и время суток не добавляют. Общая Observation, дублирующая этот факт применения, не создаётся. В реализации подтверждена классификация именно указанного кода и версии; универсальный классификатор всех иммунобиологических препаратов не заявляется. [Замечание SRC7-02](source-issues.html).

Основания: [Immunization](https://hl7.org/fhir/R5/immunization.html), [MedicationAdministration](https://hl7.org/fhir/R5/medicationadministration.html).

### Доза в потребительских единицах узла СМНН

Условие: препарат задан кодом справочника «Узлы СМНН. ЕСКЛП» (`1.2.643.5.1.13.13.99.2.611`), разовая доза — числом без unit в соответствии с руководством СЭМД редакции 7, раздел 1.22, страницы 121–122. Число означает количество потребительских единиц выбранного узла СМНН и интерпретируется вместе с кодом препарата и его версией.

Сохраняются doseQuantity.value без unit/system/code, исходное кодирование препарата и связь с Medication. В Dosage.text добавляется пояснение. Для примера:

> Разовая доза — 1 потребительская единица указанного препарата (количество в единицах выбранного узла СМНН).

Этот текст поясняет единицу дозы. Расписание, путь и особые условия приёма сохраняются в соответствующих полях Dosage и не заменяются этим предложением.

Название «Бендазол, таблетки, 20 мг|шт. (таблетка)» сохраняется, но структурированная единица «таблетка» из display не извлекается; пересчёт в мг не выполняется. Число без связанного препарата не является самостоятельной дозировкой. Для других справочников, явной единицы, диапазона или отсутствующего числа правило автоматически не применяется. Дополнительное кодирование единицы допустимо при отдельном подтверждённом терминологическом преобразовании.

Отсутствие unit предусмотрено руководством СЭМД и не считается недочётом примера. Основание: [Dosage.doseAndRate.dose[x]](https://hl7.org/fhir/R5/dosage-definitions.html#Dosage.doseAndRate.dose_x_).

### Автор записи об услуге

В секции SERVICES роль AUTHOR из НСИ `1.2.643.5.1.13.13.99.2.368` («Автор документа») интерпретируется как автор записи об услуге: ссылка передаётся в Procedure.recorder. Procedure.performer.actor сохраняется на основании исходного элемента performer; код AUTHOR не становится performer.function.

Правило не делает это лицо автоматически автором всей Composition. Исходные код, система, название и версия роли сохраняются в трассировке; её смысл выражен полем recorder. Иные роли в recorder автоматически не переводятся. Несколько AUTHOR требуют отдельного решения из-за кратности recorder 0..1; выбор первого лица недопустим.

Правило возникло при проверке редакции 5. В комплектном примере редакции 7 участник этой услуги отсутствует, поэтому recorder и performer не добавляются. Основание: [Procedure.recorder](https://hl7.org/fhir/R5/procedure-definitions.html#Procedure.recorder).

### Дата формирования связанного документа

В LINKDOCS effectiveTime записи о документе интерпретируется как дата его формирования и передаётся в DocumentReference.content.attachment.creation, даже когда файл не включён в СЭМД. Отсутствие файла обозначается отдельно; URL и data не придумываются.

Точность сохраняется: `20230502` → `2023-05-02`. При отсутствии даты creation не заполняется. DocumentReference.date относится к созданию записи ссылки, а период услуги имеет другой смысл; дату формирования туда не переносят. Исходный текст, включая возможное противоречие дат, сохраняется без клинического исправления. Основание: [Attachment.creation](https://hl7.org/fhir/R5/datatypes-definitions.html#Attachment.creation).
