# Ru SEMD Amb IG

Draft FHIR R5 Implementation Guide для представления клинического содержания протокола консультации СЭМД 290, редакция 7. Версия 0.1.0; зависимость ru.core 0.26.0. Проверенное покрытие ограничено комплектным официальным учебным примером. Это не двусторонний шлюз и не нормативная спецификация Минздрава.

Canonical: https://fhir.ru/ig/semd/amb · package: ru.semd.amb.

## Сборка

Требуются Java 21+, Node.js 20+, SUSHI 3.15.0, Python 3.11+ с зависимостями requirements.txt и Jekyll. Зафиксированный официальный архив зависимости RuCore находится в dependencies/ и проверяется по SHA-256 перед установкой в FHIR cache; обновление внешнего CI не меняет зависимость. Стандартный HL7 Publisher 3.0.1 скачивается build.sh при отсутствии локального JAR.

```sh
npm install -g fsh-sushi@3.15.0
python3 -m pip install -r requirements.txt
bash build.sh
```

Сначала воспроизводится маппинг исходного XML и 14 содержательных проверок. Затем добавляются прикладные профили и читаемые narrative, собирается IG и сохраняется reports/publisher-summary.json. Готовый сайт — output/index.html; QA — output/qa.html. По умолчанию используется https://tx.fhir.org/r5; наличие всех кодов во внешних НСИ по-прежнему не подтверждается. Сервер можно изменить через FHIR_TX_SERVER. Режим n/a допускается для диагностики, но не заменяет итоговую проверку: новый Publisher не может проверить часть обязательных привязок без сервера. Дополнительно выполняются 6 положительных/отрицательных проверок FHIRPath-инвариантов настоящим движком Publisher.

Исходный XML — официальный учебный пример из пакета ЕГИСЗ; приведённые персональные реквизиты происходят из него. Полный архив руководства и посторонние рабочие материалы не включены. Источник, хешы и границы — source/manifest.json и страницы руководства.

GitHub Actions выполняет ту же сборку при push и pull request, сохраняет сайт и QA как artifacts. Репозиторий первоначально закрытый. Открытие доступа и подключение webhook официального FHIR CI ожидают явного подтверждения публичной публикации; GitHub Actions сами по себе не публикуют сайт.
