# Ru SEMD Amb IG

Draft FHIR R5 Implementation Guide для представления клинического содержания протокола консультации СЭМД 290, редакция 7. Версия 0.2.0; родительские профили RuCore 0.26.0. Профили поддержки описывают все 28 секций редакции 7; испытания преобразования ограничены комплектным официальным учебным примером. Это не двусторонний шлюз и не нормативная спецификация Минздрава.

Canonical: https://fhir.ru/ig/semd/amb · package: ru.semd.amb.

## Сборка

Требуются Java 21+, Node.js 20+, SUSHI 3.15.0, Python 3.11+ с зависимостями requirements.txt и Jekyll. Зафиксированный официальный архив RuCore 0.26.0 находится в dependencies/ и проверяется по SHA-256. Стандартный FHIR CI не запускает скрипт подготовки кеша, а версии 0.26.0 нет в общем реестре пакетов, поэтому для доставки используется официальный канал ru.core: current. Родители AmbBundle/AmbComposition явно закреплены canonical|0.26.0 в FSH и baseDefinition: переход current на несовместимую версию приводит к ошибке сборки, а не незаметной смене основы. Стандартный HL7 Publisher 3.0.1 скачивается build.sh при отсутствии локального JAR.

```sh
npm install -g fsh-sushi@3.15.0
python3 -m pip install -r requirements.txt
bash build.sh
```

Сначала воспроизводится маппинг исходного XML и 15 содержательных проверок. Затем добавляются прикладные профили и читаемые narrative, собирается IG и сохраняется reports/publisher-summary.json. Готовый сайт — output/index.html; QA — output/qa.html. По умолчанию используется https://tx.fhir.org/r5; наличие всех кодов во внешних НСИ по-прежнему не подтверждается. Сервер можно изменить через FHIR_TX_SERVER. Режим n/a допускается для диагностики, но не заменяет итоговую проверку: новый Publisher не может проверить часть обязательных привязок без сервера. Дополнительно выполняются 30 положительных/отрицательных проверок FHIRPath-инвариантов настоящим движком Publisher.

Исходный XML — официальный учебный пример из пакета ЕГИСЗ; приведённые персональные реквизиты происходят из него. Полный архив руководства и посторонние рабочие материалы не включены. Источник, хешы и границы — source/manifest.json и страницы руководства.

GitHub Actions выполняет ту же сборку при push и pull request, сохраняет сайт и QA как artifacts. Репозиторий открыт по подтверждению оператора 18.10.2026. Подключён официальный push-webhook FHIR CI. Адрес публичной CI-сборки: https://build.fhir.org/ig/fhir-ru/RuSEMDAmbIG/. GitHub Actions независимо проверяет проект и сохраняет результаты сборки.

MustSupport относится только к получателю: см. input/pagecontent/support.md. Каталог разделов, основных и уточняющих записей: spec/edition7-content.json; воспроизводимая генерация профилей и страницы каталога — scripts/generate_content_profiles.py.
