# Ru SEMD Amb IG

- FHIR R5; canonical https://fhir.ru/ig/semd/amb; package ru.semd.amb.
- Draft 0.1.0; базовые профили подключать из ru.core0.26.0, не копировать их определения.
- Полнота определяется клиническим содержанием, не счётчиком XML-атрибутов. Не заявлять покрытие всех вариантов руководства по одному примеру.
- Перед коммитом FSH запускать bash run_sushi.sh и читать sushi_output.txt; перед публикацией bash build.sh и анализировать output/qa.html.
- Не скрывать классы терминологических ошибок общими suppressions. Внешние НСИ при -tx n/a не считаются проверенными.
- Не публиковать полный архив официального руководства или посторонние материалы. XML в source — официальный учебный пример.
- Любые предметные изменения кратко включать в проект ближайшей встречи в iCloud Meetings, как в RuCore. Не записывать согласие оператора как решение группы.
- Публичная публикация/изменение runtime требует поручения пользователя; текущая задача авторизует создание fhir-ru/RuSEMDAmbIG и синхронизацию этого проекта.
